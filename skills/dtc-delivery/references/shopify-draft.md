# Shopify Draft 交付

仅在当前任务授权上传时执行。绑定准确应用、store、theme ID、任务/worktree、目标角色、内容范围与交付模式。目标必须确认为 development 或 unpublished；不发布 Live、不从 CLI 缓存选店、不复用另一任务的绑定。

一个独立任务使用一个明确的 Draft；共享 worktree/clone/机器可能需要协调。项目有绑定登记则使用它，缺工具时显式协调，不能声称已有跨机器锁。

## 快照与基线

分别在隔离目录获取完整 Live 和目标 Draft，冻结当前本地源码及生产候选。比较范围覆盖整个主题，写入只限授权差异及必要依赖；完整比较不是全量覆盖许可。

合并模式需要已接受的 Live 祖先，以及同一目标/批次的 draftBase（目标内容）和 draftSourceBase（开发来源）。将 Draft 独有代码混入开发祖先会导致后续错误回退，必须保持两者分离。缺基线只取证并展示差异；具体覆盖可依据明确用户决定执行，但要标为覆盖而非可靠三方合并。

先完成独立的 Live 同步，再用开发来源增量规划 Draft 候选。Live 与 Draft 运营配置不同需展示逐文件方向和影响：同步已确认的 Live 配置、保留 Draft 供预览，或形成明确配置 patch。保留 Draft 不能宣称已可发布。

## 候选、配置与写入

- Draft 合成候选、专用配置和回读保存在隔离目录，禁止写回通用应用源码。普通构建不含 overlay 时不得冒充最终候选。
- 使用 [生产候选契约](production-candidate.md)，绑定源码、overlay、策略、基线、目标及最终文件内容；实际字节变化后重规划，不沿用旧回执。
- 按平台实际主题结构打包，区分 assets、config、layout、locales、sections、snippets、templates、blocks 与非主题文件。最终导入结构以当前 CLI/平台支持为准。
- 对完整差异逐项标 upload、keep-target、merge、block 或显式授权的 delete。范围外内容保持目标，不以“必要依赖”为名加入未授权业务改变。
- settings_data、模板/section-group 保存值、市场布局默认保护。明确的新模板/配置迁移独立展示 patch、兼容性和恢复；设置定义、locale 与 layout 也检查消费者。
- 检查引用、语法、schema 及受影响行为；tracking 变化按 [场景工作流](../../dtc-data-tracking/SKILL.md)。纯样式不强制全主题扫描，新组件不能只靠几张正常截图宣称全部通过。

计划写明目标身份、写入/保留/删除项、配置决定和验证边界。已有授权覆盖具体内容时继续，不重复确认；缺决定只阻断依赖项。临写重新检查目标角色、Live/目标快照和最终候选；漂移时停止并重算，连续漂移需协调稳定编辑窗口。平台没有因此获得事务锁，仍存在检查到写入间的竞态窗口。

使用安装版本实际支持的显式 store/theme/path 参数及文件范围；保护目标独有文件。CLI 的 nodelete 不等于完全镜像；精确删除需要明确范围与恢复能力。命令能力可查 [theme push](https://shopify.dev/docs/api/shopify-cli/theme/theme-push)，运行前核对当前 `--help`，不要直接执行文档占位符。

## 回读与状态

上传后从同一 store/theme 回读全部拟写文件，核对存在性与最终内容；已授权删除另验证删除结果。CLI 成功而回读失败/不同则记 uploaded-unverified 或失败，核对部分成功和并发变化，不自动重传或晋升成功基线。

局部回读只证明局部；完整基线还需保留未写内容及证据。回读成功后交接预览与回归要点，浏览器、真实编辑器、业务 UAT 按当前任务范围执行并分别记录。试用可以保留非阻断待测项；目标不明、配置覆盖风险、构建失败或已知购买对象错误不能留待试用绕过。

发布属于独立授权：发布前重新比较最新 Live 与拟发布 Draft 的全部代码/配置，避免旧 Draft 回退其他任务已上线内容。本流程不授予发布权限。

## 特殊场景

| 场景 | 处理 |
| --- | --- |
| 新 Draft | 核实创建内容；“刚创建”不证明仍等于当前 Live |
| 无差异 | 不上传；保留比较范围与身份 |
| 失败重试 | 核对原候选、目标和部分成功；同输入检查可复用 |
| 指定旧产物回滚 | 固定旧 artifact，明确配置回退范围；不按当前源码重建冒充旧版 |
| ZIP/全量覆盖 | 固定来源和哈希，列丢弃内容；覆盖不等于删除或发布 |
| 工具不支持的文件 | 列缺口与具体下一步，不静默删文件或扩大权限 |

ZIP 只是运输格式。解包前拒绝路径穿越、绝对路径和软链接，独立解压后核验清单；CLI path 应指向主题目录。后台导入可能创建新主题，不能报告成已覆盖原 Draft。保留远端内容与 intentional-overwrite 是不同承诺。
