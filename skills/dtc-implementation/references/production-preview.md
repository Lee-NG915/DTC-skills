# 生产实现与预览保持一致

## 生产资源

记录被改源码、共享编译源、锁文件、配置/入口和构建脚本身份。现有工具可生成 manifest 时采用真实 manifest；没有时记录构建输入与输出校验值，不声称已安装自动校验器。输出需要由本轮实际源码构建，不能手填哈希掩盖漏建。

直接运行的资源说明加载依据，不为了流程引入打包工具。构建链失败阻断对应交付。新依赖的生产导入、资源 URL/包路径、字体、代码分割与运行时权限必须在实际产物环境验证，开发预览成功不够。

## 预览适配

预览须调用生产组件/模板/视图，使用同一 CSS 或平台样式。fixture/provider 只补平台上下文、数据和外部 API；不要复制第二份布局或业务分支。项目有 Storybook 就使用其适用能力，没有可使用现有 harness、原生 preview 或示例页面。

Controls/参数面板来自生产类型或配置契约，保留真实 ID、标签、类型、归属、选项、min/max/step、默认/空值和条件可用性。不同实例必须有独立输入；不要用单一 JSON 或数量开关冒充全部参数已可验证。

预览辅助参数（模拟延迟、数量、故障、画布尺寸）与生产输入分组。原生资源选择器可用 URL/fixture 适配，但保留原字段与空值语义，并明确不证明真实选择器、保存、权限。

场景至少包含默认和适用宽窄屏；空/长内容、独立值、混合数据、非默认模式根据契约补齐。纯样式可沿用现有场景，不重复建框架。

若存在 iframe/画布缩放，读取实际渲染视口/容器；管理窗口宽度不是测试宽度。预览框架改变或响应式状态变更，检查面板切换和独立预览两条路径；原生平台记录设备、方向、字体缩放和实际布局边界。

## 状态与兼容

默认值判断区分 undefined/null/false/0/空字符串；每字段按契约处理，不能用统一 truthy fallback 吞掉有效值。数据来源、展示模式、布局分别判断，仅在明确业务规则下联动。

可重复组件检查操作 A 不改变 B；异步回包不覆盖更新后的选择；卸载后不触发过期事件。新增输入的旧调用方仍可渲染。共享样式/初始化变更追踪真实消费者，即使全部是新增文件也不能断言无影响。
