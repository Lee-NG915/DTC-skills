# 有边界的独立审查

用户要求审查，或共享行为、核心业务对象、配置迁移和交付范围有实质风险时，在具体 diff 与必要验证已可审阅后选择独立复核。局部纯样式不自动增加审查环节。

环境与授权允许时，可由独立上下文的审查者读取当前要求、固定基线、含未提交变化的候选、原始依据和真实测试事实；不要预设结论。审查默认只读，不修改源码或远端。若无独立审查能力则说明仅完成作者自查，不伪称干净上下文验证，也不强制安装额外服务。

输出位置、触发条件、后果、依据及最小修正；未知单列，无实际问题可以无发现。作者修正后只复查相关结论，同候选有效审查可以复用。

审查不能代替实际测试、设计证据、用户接受或发布授权，也不能证明没有任何缺陷。
