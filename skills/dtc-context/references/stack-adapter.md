# 技术栈适配契约

此表是助手在目标项目中填写的工作记录，不是已实现的插件或运行器。先发现现有能力，再映射通用阶段；选择框架、升级依赖不是流程默认动作。

| 能力 | 记录内容 | 缺失时的行为 |
| --- | --- | --- |
| 目标与源码 | 项目根、允许修改路径、组件入口、样式/字体/资源、共享消费者 | 无法定位的范围不写入 |
| 组件形态 | 函数/模板/视图/控件；组合、slot/child、事件与状态机制 | 按项目习惯实现，不强制 hooks/DOM |
| 配置契约 | 类型声明/模型/schema；外部字段身份、默认、空值和约束 | 用可审阅表声明，不冒充生成器 |
| 数据适配 | 实际 provider、加载/失败状态、fixture 边界 | 可做隔离预览，真实集成标待验 |
| 生产构建 | 实际命令、输入、依赖锁、输出与资源解析方式 | 无需编译则记录直接运行方式；需要编译但缺入口则阻断交付 |
| 预览 | 生产组件挂载入口、场景选择、参数控制、访问方式 | 可用项目原生 harness/示例屏；不强制 Storybook |
| 自动测试 | 单元、组件、集成和界面测试工具及实际调用命令 | 可用可复现手工步骤，但声明自动化缺口 |
| 视觉取证 | renderer/browser/runtime 版本、DPR/scale、字体、截图与比较方法 | 截图能力缺失时视觉待验，不用样式数值豁免 |
| 生命周期 | 挂载/更新/移除/恢复、路由、SSR/hydration（适用时） | 不支持的状态写不适用和理由 |
| 运行/交付 | 本地或远端环境、真实权限、发布/回退机制 | 本地开发无需远端 ID；无交付授权只产出候选 |

## 概念映射示例

下表仅是接口语义映射，不证明这些框架已在本仓库集成或验证。

| 通用契约 | Web 组件框架 | 服务端模板/渐进增强 | 原生/跨端视图 |
| --- | --- | --- | --- |
| 输入 | props/inputs + slots/children | context/model + template include | view properties + builder/child |
| 交互输出 | event/callback | action/form + progressive event | command/action/callback |
| 实例隔离 | 局部状态与清理 | 实例绑定和 DOM 生命周期 | view/controller 生命周期 |
| 样式目标 | CSS、布局 box、浏览器像素 | CSS 与真实服务端输出 | layout constraint、平台单位、设备 scale |
| 预览/操作 | Storybook 或现有页面 harness；已有界面测试工具 | 模板 fixture 服务和浏览器测试 | 原生 preview/simulator 和平台界面测试 |
| 视觉 | DOM 量测仅作辅助，最终对照画面 | 真实模板渲染后对照画面 | 视图边界仅作辅助，最终对照画面 |

Figma px 是来源单位，CSS px、平台逻辑单位及物理像素分别保存；不能假定自动 1:1。原生平台没有 DOM/CSS 时用等价布局与绘制证据，不跳过字体、裁切、状态和最终截图。富文本使用平台受支持的结构化 runs/spans 或安全 HTML，不能将某项目的 HTML 字段当作跨栈默认。

只对项目实际支持的环境承诺验证。SSR、服务端动作、动画、触摸、保存配置等按实际实现选择，不能凭“支持任意技术栈”宣称任意平台已验收。
