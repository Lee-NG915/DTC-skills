# 参数与场景检查、可观察断言

## 首次与增量

首次：每个新增参数记录身份/类型/归属、默认/空值、约束和消费者；有限选项覆盖语义/渲染分支，范围覆盖默认和相关 min/max/step。每个已承诺的关键状态有实际验证或显式缺口。

增量：补新参数及受影响旧项、实际消费者与兼容。共享子系统重写重新建立该范围覆盖。纯样式只做受影响视觉与资源检查；若几何改变影响命中/滚动则补对应行为。测试数量不是覆盖质量。

## 参数

| 主题 | 操作 | 可观察结果 |
| --- | --- | --- |
| 默认与空值 | 分别传未提供、null、空串、0、false（适用时） | 按契约回退/隐藏/禁用；有效值不被 truthy fallback 吞掉 |
| 类型与范围 | 枚举分支、边界、非法输入 | 合法值生效，非法输入按既定错误/降级策略处理 |
| 条件参数 | 改字段，进入无效模式，再返回 | 有意无效果有理由；恢复后的值和显示符合契约 |
| 独立实例 | A/B 输入不同，操作 A | B 的内容/样式/状态保持独立 |
| 文案强调 | 使用不含默认词的新文案；取消强调、空值、特殊字符 | 结构化强调保留，无默认短语硬编码或不安全拼接 |
| 数据资源 | 替换、缺失、双端独立值 | 实际生产消费者更新；预览辅助字段没有伪装为生产参数 |

参数面板来自生产契约。渲染字符串变化只是辅助，需要画面或实际行为证据。系统具有持久化配置且任务涵盖时，检查改→保存→重开；本地模拟只能证明适配层。

## 场景

| 场景 | 必须实际检查的行为 |
| --- | --- |
| 零/一/多项 | 合法空态、单项控件、顺序、首尾、重复项身份 |
| 混合内容 | 长短文案、有无可选标题、缺媒体、同宽异高资源；不遮挡邻项和命中区 |
| 输入方式 | 每种声明支持的按钮、键盘、触摸/拖动分别执行；鼠标不等于触摸 |
| 响应式恢复 | 非默认状态 → 改视口/方向/模式 → 切回；核对选中项、偏移、焦点和隐藏态 |
| 异步/竞争 | 成功、空、延迟、失败、重试和快速连续操作；旧回包不覆盖新状态 |
| 生命周期 | 重复挂载、更新、重排、移除、恢复；事件、订阅、计时器不重复/残留 |
| 组合页面 | 局部状态与跨区联动、导航目标、回退/错误边界、真实容器约束 |
| 可访问性 | 角色/名称、焦点顺序和可见性、键盘、对比度/动态偏好按产品环境 |

不必为每行新建文件，也不必覆盖所有参数组合。测试名称/场景注册入口沿项目实际机制更新，选中范围为空、全部跳过、仅有 scaffold 不得称通过。

## 旧消费者回归

记录改前基线、真实调用方、共享依赖、预期保留/改变行为、当前候选及命令。旧输入缺少新字段时仍符合兼容承诺；公共样式不能污染邻近组件。无法证实影响隔离时扩大检查或保留风险，不把未知当无影响。
