# 浏览器证据协议

服务入口来自当前项目能力，记录 URL、候选、用途和是否复用已有进程。端口监听不等于就绪：核 HTTP、目标页面/iframe 及必要资源 readiness。结束时只清理本次启动且不再需要的进程。

固定浏览器、CSS viewport、DPR、locale、触控和 reduced-motion；导航后等待适用的页面状态，持续连接页面不机械依赖 networkidle。先看实际 DOM/可见控件再选 role、label 或稳定 selector，不能根据初始空页猜测。

适用时收集 console/pageerror、失败请求、关键截图、父容器宽度和 iframe 宽度。操作后验证可观察结果、焦点/URL/数据变化、溢出及其他实例。声明触摸支持须有对应证据，鼠标拖拽不等于触摸。

场景围绕变化：多实例操作一处观察另一处；非默认状态切换视口再恢复；长短内容、缺资源、零/一/多项与异步失败按契约选择；动画稳定帧比较与播放行为分别验证。

每项结果绑定候选、fixture、步骤、期望来源、断言和证据。Story 存在、页面返回成功、无 console error、截图生成都不单独证明场景通过。字体/素材/代码/schema/fixture/环境变化会使相关旧结果失效；复用须明确仍适用依据。
