# 取证、资源与字体

## 逐元素清单

| 类别 | 适用取证项 | 常见误判 |
| --- | --- | --- |
| 几何 | frame、坐标系、容器/单项尺寸、可见边界、约束、对齐、gap/padding/margin | 截图缩放当 CSS 值；frame 当内容最大宽度 |
| 文字 | 分段、family、字重/样式、字号、行高、letter spacing、对齐、字符覆盖 | family 名匹配就宣称字体正确；整段粗体替代局部强调 |
| 绘制 | fills、透明度、渐变、边框、圆角、内/外阴影、模糊、遮罩与层级 | 不检查合图就二次叠加阴影；unknown 当 none |
| 布局 | auto layout/约束、固定/最大/最小/流式、溢出裁切与滚动 | 按设计分组推断真实交互；把每层都做组件 |
| 状态 | 可见性、variants、变量模式、实例覆写、不同端 | 同名节点当相同实例；漏隐藏态 |
| 资源 | 原图尺寸、裁切焦点、透明留白、内嵌文字/按钮、变换、导出范围 | 源图片边框当可见内容；导出 URL 当资源已检查 |

原始版本、读取时间分开。缺失值分别标未读取、未提供、不适用；没有完整节点树就不报总数或 100% 覆盖。移动源缺失时保留缺口，工程响应式建议不是设计原值。

## 资源策略

围绕可编辑文案、翻译、独立重排、真实交互、替换频率和出图依赖比较：

- 整图：内部固定的复杂装饰可合图；检查清晰度、可访问替代文本、双端构图和后续替换成本。
- 图文分离：独立文本或动态内容需要安全可编辑结构；检查换行、定位和对主体的遮挡。
- 混合：固定装饰合图、业务内容独立；检查底图是否残留重复文字/按钮。
- 分块：业务项需独立替换、排序、交互或复用时才细拆；检查背景连续与双端重排。

选中的方案记 DEC ID，其他方案只保留理由，不全部变成变体。素材清单记录资产 ID、来源区域、含文字/效果情况、透明要求、自然比例、采用裁切、双端是否独立、替换/缺失规则、格式与预算来源、检查状态。没有依据不规定统一 2x、固定 KB 或文件后缀。

## 字体与动态媒体

先查项目字体、系统字体策略与加载声明，匹配实际字重/样式、可变轴和字符集。复用合适资产，缺字体写明确缺口，不为每组件重新下载或改名。运行期再验证实际字形/字体加载，样式声明不等于绘制成功。

动画/视频先固定可比帧，单独验证播放、暂停、循环、交互和减少动态效果偏好。替代图只能证明布局/资源逻辑，不能证明正式素材视觉一致。
