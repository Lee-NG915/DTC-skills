# 原子与组合组件契约

在现有技术稿中为每个实际拆出的组件记录以下内容。纯装饰子层可不单独建契约，留在所属组件的规格行。

| 字段 | 内容 |
| --- | --- |
| componentId / responsibility | 唯一 ID、职责、非目标、父/子组件与消费者 |
| inputs / slots / events | 身份、类型、默认、未提供/null/0/false/空字符串语义、有效范围、输出触发条件 |
| ownership | 数据获取、业务规则、局部状态和页面状态各由谁持有 |
| variants | 真实语义分支、互斥/组合规则及不支持的组合 |
| transitions | 初始状态、动作、完成条件、错误、快速操作、恢复、更新/卸载清理 |
| styling | token/局部样式映射、布局/父容器、响应式、实例隔离 |
| content / assets | 替换、多语言、部分强调、缺失与正式/预览资源边界 |
| accessibility | 语义角色、名称、焦点/键盘/触摸及平台支持情况 |
| compatibility | 旧输入/保存数据、新字段缺省、迁移、撤回 |
| acceptance | 关联 UI row、配置检查、场景 ID 与测试入口 |

状态上提由共享消费者决定，不能强制把所有状态放全局。异步请求只在拥有它的层管理 loading/error/cancel/latest response；展示 atom 接收数据并发意图事件，不暗中绑应用服务。

控制参数与固定视觉值不同：取证得到字号不等于需要公开字号参数。token 仅在项目已采用或确有复用收益时引入，不要求每个测量值 token 化。部分强调保留安全语义结构，不硬编码默认词或字符位置；原生 spans 与 Web 富文本分别映射，不能强制 HTML。

独立双端媒体若是已确认需求，输入契约分别保留，不能以自适应 CSS 取代可独立管理。组件卸载清理订阅/计时器，重复挂载不重复绑定；无相应能力时不制造这些功能。
